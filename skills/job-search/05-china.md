# 5. 国内秋招 (China campus recruiting)

Defaults; the user may change them (write the change here).

- **The CV is not tailored.** Use the latest Chinese general CV as it is, choosing the direction (e.g. AI application / backend vs. C++ / systems) per role. No per-application review.
- **The user fills in and submits the 网申 form.** Claude helps on request: answers to free-text questions (自我评价, 项目经历, 为什么选择我们) drafted from the CV and the user's own notes, lengths counted by script; nothing invented.
- **Records:** track every application and status change in the same log or tracker as other applications.
- **Notices arrive by email** (笔试, AI 面试, 测评): see “Reading the inbox” in `03-tracking.md`. Times are Beijing time; convert to the user's local time.
- **Written tests and AI interviews:** a folder `tests/<company>/` as described in `04-interview.md`; content from the user's interview notes (八股, behavioural). Mark anything not confirmed by the official notice as “to verify”. Nothing invented, and test questions are never recorded afterwards.
